Write a file to a user-authorized SAF device folder. First use list_device_directory_hints and append the file name to the write target it returns. Provide exactly one of content or source. Use content for UTF-8 text up to 1 MiB, or source for a file in the conversation workspace, including binary files up to 100 MiB. Existing files require expected_sha256 from the current file; nothing is written when the hash does not match. Use append only when the current file was read and its hash is supplied.
